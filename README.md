# DoseQue — Technical Hiring Assessment

Welcome to the **DoseQue Technical Hiring Assessment**.

DoseQue is building a healthcare support ecosystem designed to make medication management, appointments, and patient-care services more accessible and organized. This assessment helps us understand your practical skills, problem-solving approach, code quality, and ability to build reliable software.

## 🎯 Objective

Complete the task assigned to you based on the role you expressed interest in and your relevant experience.

We evaluate **your approach, reasoning, implementation, and code quality** — not just whether the task is fully completed.

## 🧑‍💻 Assessment Process

1. Receive your assigned role-specific task and assessment instructions.
2. Read the task requirements carefully.
3. Set up your development environment.
4. Implement your solution within the given time limit.
5. Commit and push your work to your assigned GitHub branch.
6. Submit your repository link and any required notes.
7. Attend a short follow-up discussion if requested.

## 🛠️ Technology

Use the technologies specified in your assigned task. Depending on the role, the assessment may involve:

- **Frontend:** React, TypeScript, HTML, CSS, JavaScript
- **Backend:** Python, Django REST Framework, REST APIs
- **Mobile:** Flutter and Dart
- **Testing / QA:** Test cases, validation, bug identification, and test automation where applicable
- **Other roles:** Follow the technologies and requirements mentioned in your individual task.

Do not use a different framework or language unless the assessment instructions permit it.

## 📋 Candidate Instructions

- Work independently and submit your own solution.
- Read all requirements before starting.
- Write readable, maintainable, and well-organized code.
- Use meaningful variable, function, and file names.
- Handle errors and invalid inputs where relevant.
- Add a short `README.md` to your submission explaining setup and execution.
- Include sample inputs, outputs, screenshots, or tests when requested.
- Commit your work regularly with meaningful commit messages.
- Be prepared to explain your implementation and design decisions.

### AI and External Resources

Follow the specific instructions provided with your assigned task regarding AI tools, tutorials, libraries, and external references. Be transparent about any permitted assistance and ensure you can explain the code you submit.

## 🌿 GitHub Submission Guidelines

You will receive instructions about your assigned repository or branch.

If you are using a shared repository with an assigned branch:

1. Clone the repository.
2. Switch to your assigned branch.
3. Create and modify files only as instructed.
4. Commit your changes.
5. Push your branch to GitHub.
6. Open a pull request if requested.

Example commands:

```bash
git clone <repository-url>
cd <repository-folder>
git checkout <your-assigned-branch>
git status
```

After completing your task:

```bash
git add .
git commit -m "Complete assigned assessment"
git push origin <your-assigned-branch>
```

**Important:** Do not push directly to `main` or modify another candidate's work. Follow the repository-specific instructions if you receive a separate private repository.

## ⏱️ Time Limit

The expected duration will be mentioned in your individual assessment invitation. Manage your time effectively and prioritize a working, understandable solution.

If you cannot complete every requirement, document what you completed, what remains, and how you would approach the remaining work.

## 📊 Evaluation Criteria

Your submission may be evaluated on:

| Criteria                | What we look for                                   |
| ----------------------- | -------------------------------------------------- |
| Problem-solving         | Logical approach and understanding of requirements |
| Functionality           | Correctness and completeness                       |
| Code quality            | Readability, organization, and maintainability     |
| Validation              | Error handling, edge cases, and testing            |
| Technical understanding | Ability to explain your decisions                  |
| Communication           | Clear setup instructions and honest documentation  |

The exact criteria may vary according to the assigned role.

## 📤 Final Submission Checklist

Before submitting, confirm that:

-  Your code is pushed to the correct repository and branch.
-  The required functionality is implemented.
-  Setup and run instructions are included.
-  Tests or sample outputs are included when required.
-  No passwords, API keys, tokens, or other secrets are committed.
-  Your submission link is ready to share.
-  You can explain your code and decisions.

## 🤝 Professional Expectations

We value curiosity, ownership, clear communication, and a willingness to learn. If you encounter a blocker, document it clearly rather than hiding it.

Please respect the assessment deadline and keep all candidate information and assessment materials confidential.

## 📩 Questions

For questions about your assigned task, submission process, or deadline, contact the DoseQue hiring team through the communication channel provided in your invitation.
